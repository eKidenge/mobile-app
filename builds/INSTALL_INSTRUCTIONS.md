# DirectConnect App - Android APK Installation

## How to Install:
1. **Enable Unknown Sources** on your Android device:
   - Go to Settings > Security > Unknown Sources (enable it)

2. **Download the APK** from the build link

3. **Install the APK**:
   - Open the downloaded file
   - Tap "Install"
   - Wait for installation to complete

4. **Launch the app**:
   - Find "DirectConnect" in your app drawer
   - Tap to open

## App Information:
- Name: DirectConnect
- Package: com.kidenge.instantverifiedexpert
- Version: 1.0.0
- Build Type: Preview/Testing

## Testing Notes:
- This is a development build for testing
- Report any bugs or issues

## Troubleshooting:
- If installation fails, check "Unknown Sources" is enabled
- Make sure you have enough storage space
- Restart device if app doesn't launch
